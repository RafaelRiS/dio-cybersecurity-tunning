# Dependency Guardian Skill

Skill responsável por analisar dependências de projetos e identificar bibliotecas com vulnerabilidades conhecidas.

## Objetivo

Ajudar estudantes a entender:


- segurança de dependências;
- identificação de bibliotecas vulneráveis;
- análise de CVEs;
- riscos de versões desatualizadas;
- boas práticas de atualização e correção.


## Fluxo


- Entender o projeto e suas tecnologias.
- Identificar as dependências e versões utilizadas.
- Consultar fontes de vulnerabilidades conhecidas.
- Analisar os riscos encontrados.
- Recomendar versões corrigidas e melhorias de segurança.
